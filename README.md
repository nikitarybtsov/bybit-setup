# bybit-setup

Установщик рабочего места для сотрудников. Здесь лежит только скрипт установки —
секретов в репозитории нет.

Скрипт ставит на компьютер Windows необходимые программы (Python, Git, Google Chrome,
OpenSSH), скачивает рабочую копию приватного репозитория по переданному токену,
собирает изолированное окружение Python, создаёт SSH-ключ для рабочего прокси
и ярлыки запуска на рабочем столе.

## Запуск

PowerShell **от имени администратора**:

```powershell
$env:BYBIT_TOKEN='<токен>'; irm https://raw.githubusercontent.com/nikitarybtsov/bybit-setup/main/install.ps1 | iex
```

Команду с токеном выдаёт руководитель.

### Необязательные параметры

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `BYBIT_DIR` | `C:\BybitBot` | Куда установить |
| `BYBIT_BRANCH` | `master` | Какую ветку скачать |

## Повторный запуск

Безопасен. Уже установленные программы пропускаются, рабочая копия обновляется
до последней версии, существующий SSH-ключ не перезаписывается.
